# 📦 Sistema de Inventario - Proyecto Final Python

¡Bienvenido/a! Este es un sistema de gestión de inventario desarrollado en Python como proyecto final. Permite administrar de forma sencilla los productos de un negocio a través de una interfaz de consola interactiva y colorida.

## ✨ Características principales

- **CRUD completo:** Permite Registrar, Leer (Listar), Actualizar y Eliminar productos.
- **Base de datos local:** Utiliza `SQLite3` para guardar la información de manera persistente.
- **Interfaz amigable:** Usa la librería `Colorama` para mostrar mensajes de éxito, error y advertencia con colores llamativos.
- **Validación de datos:** Controla que los campos obligatorios no queden vacíos y que los precios y cantidades sean números válidos.
- **Sistema de Logs:** Registra cada movimiento importante (errores, actualizaciones, eliminaciones) en un archivo `inventario.log` para tener un historial.

## 🛠️ Requisitos

Para ejecutar este proyecto necesitas tener instalado:
- **Python 3.x** o superior.
- La librería **Colorama**.
